# Bundled sample data

`bank-marketing.csv` is the 10% `bank.csv` sample from:

> Moro, S., Rita, P., & Cortez, P. (2014). Bank Marketing [Dataset]. UCI
> Machine Learning Repository. https://doi.org/10.24432/C5K306

Source: https://archive.ics.uci.edu/dataset/222/bank%2Bmarketing

License: Creative Commons Attribution 4.0 International (CC BY 4.0).
https://creativecommons.org/licenses/by/4.0/

ControlTree changes the target column label from `y` to `term_deposit` at load
time for clarity; the bundled CSV itself is otherwise the source sample.
